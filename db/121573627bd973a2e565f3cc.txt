<h1 id="0x00-什么是xposed">0x00 什么是Xposed
</h1><p><strong>Xposed 是一款无需修改 APK 即可影响程序运行的 Hook 框架</strong>，基于它可以开发功能强大的插件 APP，实现对目标应用的注入、拦截、修改等操作，且多个功能不冲突的模块可同时运行。</p>
<p>简单来说，Xposed 的核心是 “在不改变原应用代码的情况下，动态干预其运行逻辑”，这使得它成为安卓逆向、功能扩展的重要工具。</p>
<p><a class="link" href="https://zh.wikipedia.org/wiki/Xposed_%28%E6%A1%86%E6%9E%B6%29"  target="_blank" rel="noopener"
    >Xposed (维基百科)</a></p>
<p><img src="https://raw.githubusercontent.com/fanshanng/blog_picture/master/20250921162625.png"
	
	
	
	loading="lazy"
	
	
></p>
<h1 id="0x01-xposed原理">0x01 Xposed原理
</h1><p>Xposed 的核心是<strong>劫持 Zygote 进程</strong>（安卓系统的进程孵化器，所有应用进程都由它创建），具体过程如下：</p>
<ol>
<li>用自定义实现的<code>app_process</code>替换系统原生的<code>app_process</code>；</li>
<li>加载额外的 XposedBridge.jar 包，将程序入口从系统默认的<code>com.android.internal.os.ZygoteInit.main()</code>替换为<code>de.robv.android.xposed.XposedBridge.main()</code>；</li>
<li>改造后的 Zygote 进程创建的所有 Dalvik/ART 虚拟机都会被 Hook，从而实现对所有应用进程的动态干预。</li>
</ol>
<p><del>通俗来讲，hook就是<strong>狸猫换太子</strong></del></p>

></p>

<h1 id="0x07-xposed快速hooksimplehook">0x07 Xposed快速Hook&mdash;&ndash;<strong>SimpleHook</strong>
</h1><p><a class="link" href="https://github.com/littleWhiteDuck/SimpleHook"  target="_blank" rel="noopener"
    >SimpleHook</a> 是 GitHub 用户 littleWhiteDuck 开发的一款 <strong>Android 轻量型 Hook 工具</strong>，核心定位是 “简单易用”—— 无需复杂配置即可实现常见 Hook 需求，适合对 Hook 操作复杂度要求低的用户；若需复杂功能（如自定义脚本）或更多扩展能力，官方推荐搭配 <a class="link" href="https://github.com/Xposed-Modules-Repo/me.jsonet.jshook"  target="_blank" rel="noopener"
    >jshook（复杂功能）</a>、<a class="link" href="https://github.com/Mocha-L/QuJing"  target="_blank" rel="noopener"
    >曲境（电脑端浏览器操作）</a>或算法助手（扩展功能）使用。</p>
<ul>
<li><strong>使用步骤</strong>：
<ul>
<li>在 LSPosed 中启用 SimpleHook 模块；</li>
<li>选择目标应用，添加 Hook 配置（类名、方法名、参数类型等）；</li>
<li>重启应用，配置生效。</li>
</ul>
