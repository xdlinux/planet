<p>如题</p>
<div class="highlight"><pre tabindex="0" class="chroma"><code class="language-text" data-lang="text"><span class="line"><span class="cl">[FAILED] Failed to activate swap /swapfile.
</span></span><span class="line"><span class="cl">[DEPEND] Dependency failed for Swap.</span></span></code></pre></div><p>开机时报错如上, 开机之后交换文件无法正确被挂载.</p>
<p>在Arch Linux论坛上找到了解决方案如下:</p>
<p><a href="https://bbs.archlinux.org/viewtopic.php?id=256503"target="_blank" rel="external nofollow noopener noreferrer">SOLVED: Swap not working with Kernel 5.7.2</a></p>
<p>这个问题仅出现在<code>ext4</code>文件系统下的 <code>Linux 5.7.2</code> 上, 使用<code>fallocate</code> 创建的swap交换文件.</p>
<p><a href="https://wiki.archlinux.org/index.php/swap"target="_blank" rel="external nofollow noopener noreferrer">Arch Linux Wiki</a>的解释如下:</p>
<blockquote>
<p><strong>Note:</strong> dynamic space allocation such as using <code>fallocate</code> is not supported, as it causes problems with some file systems such as <a href="https://wiki.archlinux.org/index.php/F2FS"target="_blank" rel="external nofollow noopener noreferrer">F2FS</a>[<a href="https://github.com/karelzak/util-linux/issues/633"target="_blank" rel="external nofollow noopener noreferrer">1]</a> and will likely fail to activate at boot time with error &ldquo;<em>swapon: swapfile has holes</em>&rdquo; as of kernel 5.7. Hence, contiguous allocation, such as <code>dd</code>, is the only reliable way to allocate a swap file.[<a href="https://manpages.courier-mta.org/htmlman8/swapon.8.html#swapon-8_sect3"target="_blank" rel="external nofollow noopener noreferrer">2]</a></p></blockquote>
<p><strong>因此删掉原有的<code>swapfile</code>, 用<code>dd</code>重新分配即可.</strong></p>
<div class="highlight"><pre tabindex="0" class="chroma"><code class="language-bash" data-lang="bash"><span class="line"><span class="cl">sudo dd <span class="k">if</span><span class="o">=</span>/dev/zero <span class="nv">of</span><span class="o">=</span>/swapfile <span class="nv">bs</span><span class="o">=</span>1M <span class="nv">count</span><span class="o">=</span><span class="m">4096</span> <span class="nv">status</span><span class="o">=</span>progress
</span></span><span class="line"><span class="cl">sudo chmod <span class="m">600</span> /swapfile 
</span></span><span class="line"><span class="cl">sudo mkswap /swapfile 
</span></span><span class="line"><span class="cl">sudo swapon /swapfile</span></span></code></pre></div><hr />
