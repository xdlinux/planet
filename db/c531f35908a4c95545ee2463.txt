<p>那么我们该如何利用这个<code>bd</code>呢？</p>
<p>可以看到在<code>bd</code>中存在操作<code>jmp rsp</code>, 那么其实我们可以利用这个指令<strong>跳转回栈上, 执行我们放在栈上的<code>shellcode</code></strong></p>
<p><strong>也就是说这其实是一道<code>ret2shellcode</code>的题</strong></p>
<h3 class="heading-element" id="ret2text执行过程"><span><code>ret2text</code>执行过程:</span>
 <a href="#ret2text%e6%89%a7%e8%a1%8c%e8%bf%87%e7%a8%8b" class="heading-mark">
 <svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg>

</h3><ul>
<li><strong><code>rsp</code>永远指向栈顶</strong></li>
<li><strong>当我们用常规的<code>ret2text</code>构造48字节字符串<code>+8</code>字节<code>rbp+8</code>字节<code>bd</code>函数地址 (覆盖掉原返回地址) 的<code>payload</code>时, <code>rsp</code>指向的其实是<code>bd</code>函数地址的位置</strong></li>
<li>**<code>ret</code>指令进入<code>bd</code>后弹出<code>bd</code>地址, <code>rsp</code>指向栈内储存的<code>rbp</code>的值 (预期内) **</li>
<li>**<code>bd</code>函数将<code>rbp</code>再<code>push</code>入栈中, 此时<code>rsp</code>再加8, 指向被新压入的<code>rbp</code> (预期内) **</li>
<li><strong><code>bd</code>函数执行<code>rsp</code>上的指令</strong>
那么我们就可以在<code>rsp</code>预期内指向的地址上覆盖上我们的<code>shellcode</code>使其被执行</li>
</ul>
<p>接下来就是<code>ret2shellcode</code>的:</p>

</h3><ul>
<li><strong>在<code>rsp</code>最终指向的地址放上我们待执行的<code>shellcode</code></strong></li>
<li><strong>由于长度不够, 我们可以把<code>getshell</code>的<code>shellcode</code>放在读入的字符串的最开始的地方, 再通过汇编指令进行跳转</strong></li>
<li><strong>在<code>rsp</code>所指向的位置覆盖上<code>shellcode</code>, 改变<code>rsp</code>的值使其指向<code>getshell</code>的<code>shellcode</code>并再次进行跳转, 完成<code>getshell</code></strong></li>
