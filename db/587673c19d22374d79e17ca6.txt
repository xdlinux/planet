<h2 class="wp-block-heading">Fastcgi Cache</h2>



<p>WordPress 上的缓存插件都是在 PHP 运行的过程中起作用的，Fastcgi 缓存可以将服务器的缓存前置到 Nginx，如果 Nginx 匹配到缓存文件直接返回，请求不会给到 PHP。</p>



<p>在站点的 Nginx 配置文件伪静态部分后面加上如下片段，其中加粗部分为缓存的有效时间。</p>



<pre class="wp-block-code"><code>    set $skip_cache 0;
    if ($request_method = POST) { set $skip_cache 1; }
    if ($http_cookie ~* "wordpress_logged_in_") { set $skip_cache 1; }
    if ($request_uri ~* "/wp-admin/|/wp-login.php|/xmlrpc.php") { set $skip_cache 1; }
    if ($args != "") { set $skip_cache 1; }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/tmp/php-cgi-85.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;

        fastcgi_cache WORDPRESS;
        fastcgi_cache_key "$scheme$request_method$host$request_uri";
        <strong>fastcgi_cache_valid 200 301 302 30m;
        fastcgi_cache_valid 404 1m;</strong>
        fastcgi_cache_bypass $skip_cache;
        fastcgi_no_cache $skip_cache;

        add_header X-Cache $upstream_cache_status;
    }</code></pre>



<p>在 Nginx 的全局配置文件中加上如下片段。</p>



<pre class="wp-block-code"><code>fastcgi_cache_path /www/wwwroot/fastcgi_cache levels=1:2 keys_zone=WORDPRESS:100m inactive=60m;
fastcgi_cache_key "$scheme$request_method$host$request_uri";</code></pre>



<h2 class="wp-block-heading">Gzip 和 Brotli 压缩</h2>



<p>知道创宇的加速乐本就有 Gzip 自动压缩的功能，默认开启且无法关闭。皓子的 <a href="https://howiehz.top/archives/static-resource-precompression">静态资源预压缩：零运行时开销，极致节省带宽</a> 这篇文章给我提供了一种可能的优化路径。因为原先安装的 Nginx 并没有带 Brotli 模块，所以我卸载掉重新编译安装了一个。</p>



<p>然后 apt 安装 Brotli，在网站目录里搜索 js、css 文件并生成其对应的 gz、br 文件。</p>

<p>随后，在 Nginx 站点配置文件中添加关于 Gzip 和 Brotli 压缩的设置。</p>



<pre class="wp-block-code"><code>brotli on; brotli_static on; brotli_comp_level 5;
brotli_types text/plain text/css application/javascript application/json application/xml text/html image/svg+xml;

gzip on; gzip_static on; gzip_vary on; gzip_comp_level 5;
gzip_types text/plain text/css application/javascript application/json application/xml text/html image/svg+xml;</code></pre>
