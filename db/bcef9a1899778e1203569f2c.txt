</h2><p><code>POST</code>是一种<code>HTTP</code>请求方法, 通过网址中的参数来向服务器请求相应的网络资源.</p>
<p>更详细的<code>HTTP</code>请求方法介绍, 请见: <a href="https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Methods"target="_blank" rel="external nofollow noopener noreferrer">MDN文档</a></p>
<h2 class="heading-element" id="如何post"><span>如何POST?</span>
 <a href="#%e5%a6%82%e4%bd%95post" class="heading-mark">
 <svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg>

</h2><p><code>POST</code>本质上和<code>GET</code>都属于给网站提供数据的请求方法. 只不过<code>GET</code>请求可以通过在网址后面直接构造的方法来使用, 十分的简单便捷.</p>
<p>而<code>POST</code>不同, <code>POST</code>是一种有报文的请求方式, 正常用户是无法显式看见<code>POST</code>请求的详细信息的.</p>
<p><code>POST</code>的方法有很多种, 我们只挑两种来讲.</p>

</h4><p>确保你的电脑上有<code>Python3</code>;</p>
<div class="highlight"><pre tabindex="0" class="chroma"><code class="language-bash" data-lang="bash"><span class="line"><span class="cl">$ python3 -m pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple</span></span></code></pre></div><p><strong>请注意! 不要将<code>requests</code>错误的写为<code>request</code>, <code>request</code>库近期被检出投毒: <a href="https://bbs.pediy.com/thread-261274.htm"target="_blank" rel="external nofollow noopener noreferrer">链接</a></strong></p>
<p>如果你使用<code>Linux</code>, 也可以在对应发行版的软件仓库里找到<code>requests</code>库的安装包. 例如<code>Arch Linux</code>:</p>
<div class="highlight"><pre tabindex="0" class="chroma"><code class="language-bash" data-lang="bash"><span class="line"><span class="cl">$ sudo pacman -Syyu python-requests</span></span></code></pre></div><p>即可安装<code>requests</code>库.</p>
<p>尽量使用发行版的包管理器, 这样包管理器更新时会一并检查这些包并自动升级. 如果使用<code>pip</code>, 可能还需要隔一段时间手动更新以修复一些<code>bug</code>, 获得新的功能.</p>
