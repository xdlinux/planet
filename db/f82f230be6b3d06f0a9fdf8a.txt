<h1><a id="content-讲故事" href="https://blog.lsy223622.com/archives/75/#content-%E8%AE%B2%E6%95%85%E4%BA%8B" class="heading-permalink" aria-hidden="true" title="Permalink"></a>讲故事</h1>
<ul>
<li>和朋友聊天意识到，每天有太多经历和想法在记忆中稍纵即逝，不留下记录的话以后就完全回忆不起来了，所以需要写日记。</li>
<li>我写字不好看也不快，比较习惯打字，所以记电子版的日记。</li>
<li>我希望日记使用 Markdown 格式，能够全平台多端同步，使用开源软件和开放协议。</li>
<li>以前用过一段时间的为知笔记，客户端算不上好用，导出也不方便，服务端 docker 部署但是不开源（好像），同步也是私有协议。当时可能没发现更好的就用了这个，在四个月里面断断续续记了不少，后来没坚持下去。而且为知笔记的服务端总是在服务器后台占用 10% 左右还是多点的 CPU，感觉有点不对劲。</li>
<li>这段时间因为和朋友聊得很多，每天也有很多想法，所以重新开始寻找日记的解决方案。</li>
<li>在对比了很多选择之后，选择了 Obsidian + Remotely Save 插件使用 Webdav 协议与 Nextcloud 同步的方案。</li>
</ul>
<h1><a id="content-安装配置-nextcloud" href="https://blog.lsy223622.com/archives/75/#content-%E5%AE%89%E8%A3%85%E9%85%8D%E7%BD%AE-nextcloud" class="heading-permalink" aria-hidden="true" title="Permalink"></a>安装配置 Nextcloud</h1>
<blockquote>
<p>注：以下内容只是一个简单的过程记录，没有详细步骤，而且功能只为满足日记同步需求</p>
</blockquote>
<ul>
<li>准备一个 Linux 服务器，安装 Docker 和 Nginx</li>
<li>
<code>docker-compose.yaml</code>：</li>
</ul>
<pre><code class="language-yaml">services:
  nextcloud:
    container_name: nextcloud-aio-mastercontainer
    image: ghcr.io/nextcloud-releases/all-in-one:latest
    init: true
    restart: always
    ports:
      - 8080:8080
    environment:
      - APACHE_PORT=8081
      - APACHE_IP_BINDING=127.0.0.1
      - NEXTCLOUD_DATADIR=/data/ncdata
      - SKIP_DOMAIN_VALIDATION=false
    volumes:
      - nextcloud_aio_mastercontainer:/mnt/docker-aio-config
      - /var/run/docker.sock:/var/run/docker.sock:ro
    network_mode: bridge

volumes:
  nextcloud_aio_mastercontainer:
    name: nextcloud_aio_mastercontainer
</code></pre>
<ul>
<li>然后打开 ip:8080 进行 Nextcloud AIO 的配置</li>
<li>按照说明安装好 Nextcloud 之后在 Nginx 配置反向代理，代理地址为 localhost:8081</li>
<li>访问反代到的域名，使用 Nextcloud AIO 面板提供的管理员账号密码登录</li>
<li>Nextcloud 设置很多，可以随便翻翻改改</li>
<li>在右上角菜单打开账号页面，为 Obsidian 同步添加一个账号</li>
<li>登录新的账号，在右上角菜单打开个人设置页面，在左边切换到安全标签</li>
<li>输入一个应用名称（比如“Obsidian”），点创建新应用，这样会生成一个应用密钥，妥善保存</li>
<li>Nextcloud 就配置完成了</li>
</ul>
<h1><a id="content-安装配置-obsidian" href="https://blog.lsy223622.com/archives/75/#content-%E5%AE%89%E8%A3%85%E9%85%8D%E7%BD%AE-obsidian" class="heading-permalink" aria-hidden="true" title="Permalink"></a>安装配置 Obsidian</h1>
<ul>
<li>在 <a rel="noopener noreferrer" href="https://obsidian.md/download">Obsidian 官网</a> 下载安装 Obsidian</li>
<li>打开 Obsidian，创建一个新的仓库，为它取一个名字，选择保存的目录</li>
<li>在仓库目录下创建三个文件夹 <code>Attachments</code> <code>Daily</code> <code>Templates</code>
</li>
<li>在 <code>Templates</code> 文件夹中新建一个 <code>Daily.md</code>，输入以下内容（可以是任意适合你自己的日记模板）：</li>
</ul>
<pre><code class="language-markdown"># {{date:YYYY-MM-DD}} {{date:dddd}}

## 今日待办

- [ ]

## 随手记录

-

## 心情

-

## 附件 / 链接
</code></pre>
<ul>
<li>打开设置，在 <code>第三方插件</code> 中关闭安全模式，在社区插件市场安装并启用这两个插件：<code>Periodic Notes</code> <code>Remotely Save</code>，其他插件看个人喜好，核心插件也可以选择性地开一些关一些</li>
<li>
<code>设置 - 文件与链接 - 附件默认存放路径</code> 改成 <code>指定的附件文件夹</code>，<code>附件文件夹路径</code> 选择 <code>Attachments</code>
</li>
<li>启用 <code>设置 - Periodic Notes - Daily Notes</code>，<code>Daily Notes Template</code> 选择 <code>Templates/Daily.md</code>，<code>Note Folder</code> 选择 <code>Daily</code>
</li>
<li>
<code>设置 - Remotely Save - 选择远程服务</code> 选择 <code>Webdav</code>，<code>服务器地址</code> 填 <code>https://&lt;你的Nextcloud域名&gt;/remote.php/dav/files/&lt;同步用户名&gt;/Obsidian</code>，用户名填刚设置的同步用户名，密码填刚生成的应用密码（不要用用户主密码！）</li>
<li>depth header 选支持 infinity，自动运行、启动后自动运行一次、保存时同步我是都开了</li>
<li>然后关掉设置，点击窗口最左边一列图标中的 <code>Open today</code>，开始写日记吧！</li>
</ul>
<p>各种平台的应用都按相同方式配置一遍就能互相同步啦~</p>
