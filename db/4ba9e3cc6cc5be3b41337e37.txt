<h1 id="Windows-上自定义按键映射">Windows 上自定义按键映射<a class="headerlink" href="#Windows-上自定义按键映射" title="Permanent link">&para;</a></h1>
<p>针对我的奇怪需求，使用 Win API 实现了</p>
<ul>
<li>禁用 <code>num lock</code></li>
<li>将 <code>caps lock</code> 映射成 <code>win + space</code></li>
<li>将键盘布局状态同步到 <code>caps lock</code> 的 LED 指示灯</li>
</ul>
<p>代码开源在 <a href="https://github.com/stalomeow/KeyboardRemapper">stalomeow/KeyboardRemapper</a>。</p>
<!-- more -->

<h2 id="安装">安装<a class="headerlink" href="#安装" title="Permanent link">&para;</a></h2>
<p>使用 <a href="../../n/eccf-afeg-cech/">Scoop</a> 从 <a href="https://github.com/stalomeow/ScoopBucket">stalomeow/ScoopBucket</a> 安装。</p>
<div class="highlight"><pre><span></span><code>sudo<span class="w"> </span>scoop<span class="w"> </span>install<span class="w"> </span>stalo/keyboard-remapper
</code></pre></div>
<p>开机会自动启动。</p>
<h2 id="按键映射">按键映射<a class="headerlink" href="#按键映射" title="Permanent link">&para;</a></h2>
<p>使用 <a href="https://learn.microsoft.com/en-us/previous-versions/windows/desktop/legacy/ms644985(v=vs.85)">LowLevelKeyboardProc</a> 实现，代码可以借鉴 <a href="https://github.com/microsoft/PowerToys/tree/main/src/modules/keyboardmanager">PowerToys KeyboardManager</a>。</p>
<h2 id="同步指示灯">同步指示灯<a class="headerlink" href="#同步指示灯" title="Permanent link">&para;</a></h2>
<p>使用 <a href="../../n/eabe-abdh-cfad/">Windows 全局钩子</a> 监听键盘布局变化（<code>HSHELL_LANGUAGE</code>）事件，然后根据当前布局设置指示灯状态。</p>
